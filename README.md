# season1blue.github.io

Minimal English personal homepage for Shezheng Song.

## Publish on GitHub Pages

1. Create a public repository named \`season1blue.github.io\` under the GitHub account \`season1blue\`.
2. Upload \`index.html\` and \`styles.css\` to the repository root.
3. Open **Settings -> Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the \`main\` branch and the \`/ (root)\` folder.
6. Save and wait for the deployment to finish.

The site will be available at https://season1blue.github.io
